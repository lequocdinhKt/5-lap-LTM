Mini Web Server đang hoạt động

Trang này được trả về bằng HTTP/1.1 do chương trình Java tự xử lý trên TCP Socket.

Tài nguyên tải xuống

  • Tài liệu PDF
  • File nhạc MP3
  • File video MP4

Hãy chép ba file thật vào www/files trước khi kiểm thử tải xuống.

Chức năng cần thử

Dùng Mini Browser để gửi GET, HEAD, POST và tải file. Thử một URL không tồn tại để xem lỗi 404.
